# Apple Cinema Gold 1.4.0 для Lampa

Неофициальная пользовательская надстройка для **Lampa на Android TV**: кинематографичный Hero-баннер в эстетике Apple TV, тёмно-золотая палитра и увеличенное верхнее меню.

> **Статус:** экспериментальная сборка. Проверена синтаксическая корректность JavaScript; полноценная проверка на реальном Android TV не проводилась. Возможны конфликты с другими темами.

## Возможности

- Большой фон и информация о фильме на главной странице (через внешнюю зависимость AppleTV AgNative NG).
- Верхняя панель по умолчанию 2,25×, с горизонтальной прокруткой. В ней категории «Мультфильмы», «Фильмы», «Сериалы» и доступные из установленных расширений «Дорамы», «Каталог», «Фильтр», «Избранное».
- Боковое меню и настройки оформлены сдержанными оттенками шампань и матовым стеклом. Их размер не меняется.
- В Hero-баннере предусмотрены действующие действия «Смотреть» (через карточку фильма и её источники), «Подробнее» и «В папку/избранное». На странице фильма используются штатные обработчики кнопок Lampa.
- Карточки фильмов в горизонтальных каруселях увеличены на 25% по ширине как для горизонтальных фоновых обложек, так и для обычных вертикальных постеров.
- Цветовые режимы: тёмное золото, классическое золото и без золотой палитры.
- Настройки отключения оформления и восстановления параметров, изменённых надстройкой.
- Без встроенных библиотек фильмов, видеопотоков и функций обхода подписок.

## Новое в 1.4.0

- Навигация по верхним категориям сохраняет исходные маршруты Lampa; отсутствующие категории не создаются искусственно. Для «Дорам», «Каталога» и «Фильтра» нужен соответствующий пункт установленного расширения.
- Сверху остаются поиск, обновление и аккаунт; дополнительные системные действия доступны в боковом меню.
- Если установленная Remote-клавиатура предоставляет узнаваемую кнопку в шапке, она переносится в боковое меню; при отсутствии такой кнопки функция не скрывается.
- На странице фильма выполняется попытка автоматического воспроизведения трейлера с YouTube без звука после короткой задержки. Запрос видео выполняется через TMDB, используется не более одного активного ролика. При отсутствии трейлера остаётся фоновый постер. Воспроизведение может блокироваться Android WebView или YouTube. Пункт «Фоновый трейлер в карточке» позволяет отключить функцию.
- В главном Hero-баннере основное управление с пульта опирается на AppleTV AgNative NG. Для дополнительных кнопок предусмотрены обработчики выбора; полную совместимость с пультом необходимо проверить на устройстве.

## Установка

1. Сохрани важные настройки Lampa и отключи другие расширения, полностью изменяющие главную страницу: Snack TV, Netflix UI, другие темы Apple TV и отдельный Gold Theme.
2. В GitHub открой **Settings → Pages → Build and deployment** и выбери **Deploy from a branch**, ветку `main`, папку `/(root)`.
3. Используй адрес `https://lqllisa.github.io/apple-cinema-gold/apple_cinema_gold.js` в Lampa → Настройки → Расширения → Добавить плагин.
4. После установки перезапусти Lampa. В разделе Apple Cinema Gold можно выбрать палитру и размер верхнего меню.
5. В случае ошибки вернись к прежней теме через настройки или используй аварийный режим удаления расширений, если он поддерживается твоей версией Lampa.

## Технические ограничения

- Скрипт зависит от доступности [AppleTV AgNative NG](https://llowmikee.github.io/AppleTVAGNativeNG/appletv_agnative.js).
- При первом обновлении прежний размер по умолчанию 1,5× увеличивается до 2,25×. Остальные вручную выбранные размеры сохраняются.
- «Смотреть» и добавление в избранное используют штатные функции карточки фильма. При отсутствии доступного источника просмотр не запустится.
- Устанавливай только одно расширение, существенно меняющее главную страницу, за раз.
