# Apple Cinema Gold 1.8.0

Неофициальное оформление Lampa для Android TV: тёмное стекло, светлый акцент шампань и кинематографичная композиция.

Установка: <https://lqllisa.github.io/apple-cinema-gold/apple_cinema_gold.js>

## Изменения 1.8

- У выбранного фильма один ровный внутренний контур. Радиусы изображения и рамки совпадают; конфликтующие увеличения, наклоны и смещения карточек отключены.
- Фоновый трейлер включён по умолчанию. До начала воспроизведения, при ошибке и во время буферизации виден постер. При возобновлении видео фон возвращается автоматически. Переключатель из карточки убран; общая настройка сохранена.
- «Аниме» перенесено из бокового меню в центр верхней панели. Подписи и горизонтальные отступы подогнаны под девять категорий; высота панели и размеры отдельных системных кнопок сохранены. При недостатке ширины категории прокручиваются с фокусом.
- Shots отключён только на главном экране через штатный параметр Lampa. Заголовки всех каруселей увеличены на 20%.
- Установлен встроенный размытый фон выбранного фильма. Приглушённые цвета постера видны на тёмной основе, смена изображения и кэширование остаются на стороне Lampa. Дополнительного полноэкранного фильтра или цикла анимации нет.
- Отступ под верхней панелью перенесён в неподвижную часть вертикального скроллера. При переходе между рядами заголовок выбранного ряда остаётся под панелью. Устранён лишний отступ во вложенных горизонтальных каруселях.
- Сохранены жанровые теги, краткое описание, единая кнопка закладки, оформление Amedia, отдельные системные кнопки и расстояние между рядами.

## Действия и настройки

«Смотреть» открывает штатный выбор источника Lampa. Amedia запускает собственный установленный источник. Плагин оформления не устанавливает видеопровайдеров.

В верхнюю панель переносятся существующие разделы. Аниме, дорамы, каталог и фильтр появляются при наличии соответствующих пунктов в Lampa или расширениях. Распознанная Remote-клавиатура остаётся в боковом меню.

Кнопка закладки вызывает действие коллекций установленного расширения, если оно доступно в карточке. Иначе открывается штатный выбор закладок Lampa. Отдельное хранилище произвольных подборок плагин не создаёт.

Настройки → Apple Cinema Gold:

- Размер верхней панели: исходный, +10% или +20%. По умолчанию +20%; выбор размера из версии 1.7 сохраняется.
- Расстояние между каруселями: умеренное, свободное или максимальное. Предыдущий выбор сохраняется.
- Фоновый трейлер в карточке: включить или выключить. При первом переходе на 1.8 он включается; последующий выбор сохраняется между запусками.
- Упростить стеклянные эффекты: уменьшить нагрузку на слабый телевизор. По умолчанию стекло размывается и на телевизорах, которые AgNative автоматически относит к облегчённому режиму.
- Восстановление прежних параметров оформления.

Трейлер появляется только после подтверждённого воспроизведения и играет без звука. При ошибке или буферизации сохраняется постер и доступен ручной просмотр. YouTube должен быть доступен устройству, ролик должен разрешать встраивание, а WebView должен поддерживать воспроизведение. Настройка не снимает сетевые ограничения или запреты автозапуска. Доступность видеопотока на конкретном телевизоре не гарантируется.

## Обновление

Ссылка установки осталась прежней. Полностью закрой и снова запусти Lampa. Версия в настройках Apple Cinema Gold должна быть 1.8.

Для новой установки добавь адрес в Lampa → Настройки → Расширения. Не подключай одновременно несколько тем, полностью заменяющих главную страницу.

## Сборка и проверка

Устанавливаемый `apple_cinema_gold.js` собирается из `src/plugin.js` и `src/styles.css`:

```sh
python3 build.py
npm ci
npm test
```

Python нужен только для сборки, Node и jsdom только для проверок. Они не загружаются на телевизор. `trailer.html` публикуется рядом со скриптом на GitHub Pages и должен оставаться доступным.

27 DOM-проверок охватывают позднюю загрузку элементов, навигацию пультом, действия закладки и источников, перенос «Аниме», миграцию настроек, отключение Shots, запуск и отмену трейлеров, восстановление постера и проверку отправителя сообщений.

Дополнительно проверен каскад CSS с исходными стилями Lampa и AgNative в режимах high/low/ultra при обоих порядках загрузки, включая одинаковую толщину рамки, отсутствие обрезания углов и отступ под панелью. Расчёт переходов вверх и вниз проверен с текущим модулем Scroll Lampa на геометрических моделях 1280×720, 1920×1080 и 3840×2160, с главным баннером и без него. Это не проверка рендеринга или воспроизведения на физическом телевизоре.

Принципы материалов и фокуса сверены с [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/materials/), события плеера и причины отказа со [справочником YouTube IFrame API](https://developers.google.com/youtube/iframe_api_reference).
