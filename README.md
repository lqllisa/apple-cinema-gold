# Apple Cinema Gold 1.6.0 для Lampa

Неофициальная надстройка для Lampa на Android TV с композицией по референсу Apple TV: большой фон, информация слева, светлая кнопка просмотра и компактные круглые действия.

Адрес установки сохранён:

```text
https://lqllisa.github.io/apple-cinema-gold/apple_cinema_gold.js
```

## Изменения 1.6.0

- Уменьшена верхняя панель. Кнопки меню и аккаунта получили отдельное место по краям; категории прокручиваются внутри панели. Поиск и обновление остаются сверху, распознанная Remote-клавиатура переносится в меню.
- Предпросмотр содержит настоящие кнопки «Смотреть», «В избранное», «В папку или подборку», «Подробнее» и «Следующий фильм». Исправлена навигация между действиями с пульта. Вместо псевдоэлемента «Подробнее» используется исходная кнопка с сохранённым обработчиком.
- Добавлены жанровые теги и строка сведений: год, фильм/сериал, рейтинг, хронометраж, возрастная отметка, число сезонов и серий. Показываются только имеющиеся данные. Краткое описание ограничено тремя строками.
- Шапка карточки оформлена в той же композиции: крупный фон, название и описание слева, постоянно видимая надпись «Смотреть», избранное и другие штатные действия.
- Коричневые градиенты кнопок заменены светлой однотонной заливкой и графитовыми второстепенными кнопками. Фокус обозначается светлым контуром.
- Вместо минимальных отступов исходной темы задан заметный интервал между каруселями. В настройках доступны умеренный, свободный и максимальный варианты. Сохранено увеличение ширины карточек на 25% и поддержка размеров AgNative.
- Масштаб элементов рассчитывается из фактического размера интерфейса Lampa. Старое значение верхней панели 2,25× при обновлении сбрасывается на компактное.
- Переработаны фоновые трейлеры. Сначала используются видео, уже полученные Lampa, затем её API. YouTube загружается через небольшую HTTPS-страницу `trailer.html`, чтобы в приложениях с локальным адресом `file://` у встроенного плеера был настоящий веб-источник. Отправитель сообщений плеера проверяется по окну, адресу и идентификатору.
- Трейлер появляется только после подтверждения воспроизведения и играет без звука. При ошибке или блокировке автозапуска сохраняется постер. Переход на другую страницу, запуск основного плеера и ручной выбор трейлера останавливают фон.
- Декорирование предпросмотра работает и после медленной загрузки. Начальный опрос ограничен по времени, наблюдатели привязаны к нужным контейнерам, кеш трейлеров ограничен 20 записями. Сохранён облегчённый режим эффектов AgNative для слабых телевизоров.

## Действия и ограничения

«Смотреть» открывает карточку и запускает её штатный выбор источника. Для просмотра нужен установленный источник. Избранное сохраняется через `Lampa.Favorite`.

Кнопка папки вызывает действие коллекций установленного расширения, если оно доступно в карточке. Иначе открывается штатный выбор закладок Lampa. Отдельное хранилище произвольных пользовательских подборок этот плагин не создаёт.

В верхнюю панель переносятся существующие разделы. Дорамы, каталог и фильтр появляются при наличии соответствующих пунктов в Lampa или установленных расширениях.

YouTube должен быть доступен устройству, а конкретный ролик должен разрешать встраивание. Автоматическое воспроизведение зависит от Android WebView. Кнопка ручного просмотра использует штатный обработчик трейлеров Lampa, когда он доступен. Реальное воспроизведение на телевизоре этой сборкой не проверялось.

## Обновление

Если плагин уже установлен по указанному адресу, менять ссылку не нужно. Полностью закрой и снова запусти Lampa. Версия в настройках Apple Cinema Gold должна быть 1.6.

Для новой установки добавь адрес в Lampa → Настройки → Расширения. Не подключай одновременно несколько тем, полностью заменяющих главную страницу. Настройки Apple Cinema Gold позволяют изменить размер верхней панели, расстояние между каруселями, отключить фоновый трейлер или восстановить прежние параметры.

## Сборка и проверка

Устанавливаемый `apple_cinema_gold.js` собирается из `src/plugin.js` и `src/styles.css`:

```sh
python3 build.py
npm ci
npm test
```

Python нужен только для сборки, Node и jsdom только для проверок. Они не загружаются на телевизор. `trailer.html` публикуется рядом со скриптом на GitHub Pages и должен оставаться доступным.

Проверяются позднее появление предпросмотра, навигация пультом, возврат к сохранённой странице, избранное, переход к штатным действиям, сообщения фонового плеера, отмена устаревших запросов, ошибки YouTube и отключение оформления. Это проверки DOM с имитацией событий Lampa и плеера; они не заменяют проверку изображения и воспроизведения на реальном Android TV.
